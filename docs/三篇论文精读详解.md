## 第〇部分：公共地基（三篇共享的前置知识）

### 0.1 异常检测的统一设定：OCC（单类分类）

三篇论文共享同一个任务设定，术语叫 **One-Class Classification / 无监督异常检测**：

> **训练时只有正常样本，测试时模型要回答：这个新样本是正常还是异常？如果是异常，指出哪里异常。**

为什么是这个设定？工业里的现实：**缺陷样本稀少、种类不定、标注昂贵**。你没法为每种缺陷各收集一万张样本训练分类器——缺陷要是能批量生产，那产线早该停了。所以学术界把问题统一成"只学正常，没见过的东西就是异常"。

对应到三篇论文：
- **Real3D-AD**：训练集 = 每类 4 个无缺陷原型；测试 = 正常/缺陷工件
- **3D-CSAD**：更极端——**连训练集都不要**，单个样本自己检自己
- **Constricting**：训练集 = 正常视频帧；测试 = 异常帧

### 0.2 怎么评：AUROC 与 AUPR

三篇都用（或可以用）这两个指标，必须先懂。

**AUROC**（ROC 曲线下面积）：模型给每个样本打一个"异常分数"，分数从高到低排序，走遍所有阈值，画出"检出率（TPR）vs 误报率（FPR）"曲线，算面积。
- **AUC = 0.5** ≈ 抛硬币（随机排序）；**1.0** = 完美排序
- 直觉：**AUROC 衡量"模型把异常排在正常前面的能力"**，与阈值无关
- Real3D-AD 表 4 里"现有方法 AUROC 不到 50%"的意思：它们把一半缺陷排在了正常样本后面——比瞎猜还差点

**AUPR**（PR 曲线下面积）：查准率-查全率曲线下的面积。与 AUROC 的差别在**类别极度不平衡时更重要**（比如点级检测：一张图 99% 点正常）。这时 AUROC 会显得"虚高"，AUPR 更严格。

**两粒度**：物体级（整个工件判正常/异常）+ 点级/像素级（每个点判是否缺陷）——三篇都同时报两个粒度。

### 0.3 异常检测的两条哲学路线（看懂三篇论文的总地图）

| 路线 | 核心思想 | 代表 | 本文档中的位置 |
|---|---|---|---|
| **建模范式** | 学一个"正常"的表示，测试样本离它越远越异常 | PatchCore 记忆库、师生网络、AE 重建 | Real3D-AD（Reg3D-AD）、Constricting |

两条路线不互斥，但假设来源完全不同：前者假设"训练数据能代表正常"，后者假设"正常样本本身有数学规律"。

## 论文一：Real3D-AD —— 高精度点云异常检测数据集与基准

> 一句话：造了个"毫米级工件、微米级点距、360° 无盲区"的真 3D 质检数据集，顺手搭了 benchmark，发现现有方法全线不及格，于是提出配准+记忆库基线 Reg3D-AD。

### 1.1 WHY：为什么要写这篇论文（第 1 节逐段拆）

**第一段——动机链**：
点云质检是工业刚需 → 但学术界能用的 3D 数据集全是 RGBD → RGBD 有盲区 → 所以必须造真 3D 数据集。这条链的每一环都要能自己复述。

**第二段——现有数据集的三大局限（全文精华，逐条拆）**：

**局限 1：精度不够。** 对比 MVTec 3D-AD（他们 2022 年用的 Zivid 相机）：
| 指标 | MVTec 3D-AD | Real3D-AD | 差距 |
|---|---|---|---|
| 每件点数 | ~4,147 | ~130 万 | **~100 倍**（论文按类别不同 30×–400×） |
| 点精度 | 0.11 mm | 0.011 mm | **10 倍**（论文写 9 倍） |
| 空间间距 | 0.37 mm | 0.04 mm | **4.28 倍** |

为什么"点距 0.37mm"在质检里是致命的？想想你 Day 3 做的双阈值缺陷检测：缺陷要在数据里有"存在感"。一个直径 0.2mm 的划痕，落在点距 0.37mm 的采样里——**一整条划痕可能只占 1–2 个点**，直接被采样过程抹掉。而点距 0.04mm 时，同一条划痕有 5 个点的宽度，还测得出深度。**点距决定了你能看见多小的缺陷，点精度决定了你测得多准。**

**局限 2：单视角盲区。** RGBD = 一个固定机位拍的深度图，只覆盖正对相机的那一面。背面、侧棱、自遮挡区 = 盲区。Real3D-AD 用转台 360° 扫描 + 翻面拼接，全表面覆盖。

**局限 3：仿真数据保真度不够。** Eyescandies 用 Blender 渲染糖果——纹理和异常细节都是"画"出来的，跟真实机加工缺陷（崩边、划痕、凹陷）的物理形态对不上。

**第三段——benchmark 的发现（刺眼的事实）**：他们在自己的数据集上测了 7 种方法变体（BTF×2、M3DM×2、PatchCore×3），**物体级 AUROC 平均最高才 0.682（PatchCore+FPFH+Raw），多数不到 0.6，M3DM-PointBERT 只有 0.538**。意思是：这套高精度 + 小样本 + 单面测试的设定，把现有方法集体打回原形。这就是"揭示 baseline 缺失"的含义。

### 1.2 WHAT：数据集长什么样（第 3 节）

**采集设备**：PMAX-S130 高分辨率蓝光双目扫描仪。蓝光滤光片的物理原理值得记一笔：环境光里蓝光成分少，镜头只放行特定波长蓝光 → 车间复杂光照下抗干扰。这是"硬件层面解决数据质量问题"的思路，和你写代码无关，但体现了工业采集的工程思维。

**原型（prototype）构建**（图 3）：转台扫 360° → 翻面再扫 → 人工校准 + 算法拼接 → 有缺损就重扫。**每件原型 1.2 天 × 3 人**。这就是为什么训练集只有 4 个/类——不是不想多给，是造不起。

**异常制造与标注**（图 4-5）：
- 两类点云异常：**残缺（incompleteness）** 与 **冗余（redundancy）**——数据集里叫 sink / bulge
- 残缺标注的讲究：**把横截面和断裂边缘标为异常，且标注不引入额外点**（图 5）。这句是防"标注本身污染点云"
- 工具：CloudCompare，七人团队四个月

**统计特性（表 2 解读）**：
- 12 类（飞机、糖果棒、小鸡、钻石、鸭子、鱼、宝石、海马、贝壳、海星、太妃糖、汽车），全是透明/半透明玩具产品——**透明物体正是 2D 视觉的死穴**（结构光都费劲），点云反而稳定，这是数据集的任务设计巧思
- 训练 4 个原型 / 测试正常 ~50 / 测试异常 ~50 / 共 1254 件
- **异常点占比 Δ 只有 1.18%–5.41%（均值 3%）**：每 100 个点里只有 3 个是缺陷。这是全文第二刺眼的事实——比 MVTec 2D（缺陷区域通常 5%–30%）难一个量级。阈值稍松就淹没在误报里

**箱线图（图 6）的两个读法**：
1. 训练样本（完整原型）点数 ≫ 测试样本（单面扫描）——分布天然不一致
2. 同一测试集内正常/异常点数差异很小——**不能用"点数多少"当判据**，必须靠几何

### 1.3 HOW：ADBench-3D 与 Reg3D-AD（第 4 节，本篇的算法核心）

**问题定义（4.1 节）**：
- 形式化：训练集 T = {t₁…t_N}，每个 t 属于某类别 cⱼ；测试时给 cⱼ 类的一个样本，要判正常/异常，异常还要定位
- 三个挑战：① 训练集只有正常原型、无标注 ② 原型极少（≤4）③ 测试单面扫描 vs 训练完整原型，**空间分布必然有差异**

**被测的 7+1 种方法（表 4 的方法学意义，每一列怎么读）**：
| 方法 | 本质 | 特征 |
|---|---|---|
| BTF(Raw) | 手工特征 + 记忆库 | 只用 xyz 坐标 |
| BTF(FPFH) | 同上 | FPFH 33 维 |
| M3DM(PointMAE/PointBERT) | 预训练点Transformer + 记忆库 | 深度学习特征 |
| PatchCore+FPFH(+Raw) | PatchCore 框架换 3D 特征 | 你库里 01 号论文的思想直接搬运 |
| PatchCore+PointMAE | 同上 | 深度特征版 |
| **Reg3D-AD（本文）** | 配准 + 双特征记忆库 | 见下 |

**Reg3D-AD 流水线（图 8 + 式 1-3，逐公式精讲）**：

第 0 步 **配准**：测试点云先经 RANSAC 配准到训练原型上。
- 为什么必须配准？测试是单面、训练是整只，姿态/位置都不同；"同一表面位置"在原始坐标里对不上号。配准 = 给两边的点建立"同一个物理位置"的对应。**这一步的失败模式直接决定上限**——论文局限性里"边缘截断导致误检"就是指这个。
- 🎯 这就是你 Day 4 练习 3 的 RANSAC，论文里一模一样。

第 1 步 **双特征提取**：
- **局部特征 = 坐标 (x,y,z)**：点的位置本身。优点：精确；缺点：对姿态敏感（所以前面必须配准）
- **全局特征 = PointMAE 特征**：预训练点云 Transformer 给的语义化描述。优点：概括性强；缺点：粗
- 两条特征路并行，各自建一个记忆库 M_l（局部）和 M_g（全局）。**"局部管定位精度，全局管整体判断"**是双特征设计的直觉。

第 2 步 **记忆库 + Coreset**：训练原型的全部特征存进记忆库，太大就 Coreset 采样（贪心选"最有代表性"的子集，控制规模）。你库里 PatchCore 论文的核心机制。

第 3 步 **打分（式 1-2，本论文最该逐行读懂的三行）**：

$$m_{test,*} = \arg\max_{m_{test} \in P(x_{test})} \min_{m_l \in M_l} \|m_{test} - m_l\|_2,\quad m_l^* = \arg\min_{m_l \in M_l} \|m_{test} - m_l\|_2$$

翻译成人话：
1. 对测试样本的**每个点**的特征 m_test，去记忆库里找最近邻 m_l*，算距离 ‖m_test − m_l*‖₂ —— "这个点离见过的最正常的东西有多远"
2. 再取**所有点里这个距离的最大值**作为样本分数 —— "**一个工件只要有 1 个点足够离群，整个工件就是异常的**"

为什么用 max 而不是 mean？因为缺陷是**稀疏**的（Δ≈3%）。若用 mean，99% 正常点会把 1% 缺陷点的信号平均掉。max 是"一票否决"——这正是"阈值要在噪声极值与缺陷信号之间找空档"思想的体现（🎯 Day 3 练习 4 你推导过 4 万样本期望极值 4.06σ，还记得吗？这里 max 的统计性质就是那次的延伸）。

第 4 步 **PatchCore 加权（式 3）**：

$$s_l = \Big(1 - \frac{\exp\|m_{test,*} - m^*\|_2}{\sum_{m \in N_b(m^*)} \exp\|m_{test,*} - m\|_2}\Big) \cdot s_l^*$$

直觉：如果最可疑的那个点，跟记忆里**一大片区域**都远（分母大），那它可能是正常的类内变化（比如换个角度）；如果只跟极个别记忆远（分母小），才是真异常。这是个软化的"邻近密度校准"。实现时可以做，第一版复现可先跳过（v1 用裸 max 距离）。

第 5 步 **合成**：s_t = (s_l + s_g)/2，局部全局各半。

**附录细节（跑复现要照抄的数字）**：
- BTF：训练点采样存 100:1，测试 500:1，KNN 回填未采样点分数
- M3DM：point transformer 点组数 16384
- PatchCore 系：记忆库大小 10000
- 消融（表 8）：**PointMAE 点组数变大 → 性能变好；记忆库变大 → 不一定变好**（记忆库冗余，Coreset 的意义）

**结果怎么读（表 4-7）**：
- 物体级 AUROC：Reg3D-AD 均值 **0.704 第一**；PatchCore+FPFH+Raw 0.682 第二
- 点级 AUROC：Reg3D-AD (0.700) 反输 BTF(Raw) (0.722) —— 作者如实承认
- 点级 AUPR：Reg3D-AD (0.113) 反输自家 PatchCore+FPFH+Raw (0.129)
- **学术诚实点**：作者在附录里把输掉的指标也全列了，"总体而言是可靠基线"。读论文要看这种地方——作者自己暴露的弱点比优点更值钱

**为什么现有方法集体崩溃？（本论文最重要的思考题）**
表 4 的设定 ≈ 小样本异常检测（每类 4 原型）+ 高精度点云 + 单面测试。现有 SOTA（BTF/M3DM）是给 MVTec 3D-AD 那种"大训练集 + 低精度"场景设计的：记忆库需要足够多的正常样本来覆盖类内变化，4 个原型覆盖不住；MVTec 点距 0.37mm，同样的几何偏差在 0.04mm 点距下信号形态完全不同。**数据集换了物理量级，算法的所有默认假设都要重新审。**

### 1.5 📝 自检三问（论文一）

**Q1**：用自己的话解释：为什么"深度图"不是真 3D？提示：想想 Day 2 你处理的高度图——`HEIGHT×WIDTH` 的组织形式隐含了什么几何假设？
答案藏在 H×W 这个组织形式里。 一张深度图是 HEIGHT×WIDTH 个像素，每个格子只存一个深度值——这个结构本身就偷偷做了一个几何假设：

从相机看出去，每根视线只穿过物体表面一次。

数学上说，它假设世界是一个单值函数 z = f(x, y)：每个 (x, y) 位置只允许有一个高度。

你 Day 3 的高度图就是这结构的亲儿子：height[iy, ix] = mean(z)，60×60 个格子，每格一个数。当时你没觉得别扭，因为平板恰好满足这个假设。但只要物体复杂一点，假设立刻破产：

        
 
耳朵（下方还有头）→ 一个 (x,y) 对应两个面，深度图存不下；
背面/底面 → 视线根本到不了，连被存的资格都没有；
竖直墙面 → 投影到一个 (x,y) 附近，深度突变混成一团。
所以深度图是 2.5D：比 2D 照片多半层深度信息，但只是"朝向你的一层皮"，像浮雕，不是雕像。真 3D 点云是一堆无网格约束的 (x,y,z)，同一根柱子可以存任意多个点，360° 都有数据——浮雕和雕像的差别。

一句复述：深度图的 H×W 网格隐含"每个 (x,y) 只有一个高度"的假设，这个假设排除了悬空、背面、竖直面，所以深度图只是单视角的一层皮（2.5D)，不是真 3D。
- 关键句：深度图是"从单一视点看过去的函数" z = f(x,y)，每个 (x,y) 只许有一个 z——它假设表面沿视线方向**不折叠**
- 反例：物体背面、侧棱、凹陷自遮挡处，在这个假设下没有表示（或表示错误）
- 对照：真 3D 点云是表面本身的采样，与视点无关，可 360° 覆盖
- 检验标准：你的答案里有没有出现"单视点/视线方向/遮挡"这组词

**Q3**：只有 4 个训练原型，"训练一个分类器/AE"还走得通吗？写下你的直觉。


分类器死路：分类器要学的是"正常 vs 异常"的分界线，而异常样本一个都没有——连"线的另一边"都没见过，无从画线。这条路缺的不是数据量，是整整一类数据。

AE 死路（只学正常）：自编码器靠"见过很多正常的不同样子"来学会"什么是正常"。4 个样本意味着：

学紧了：把 4 个原型背下来（过拟合），第 5 个正常工件摆的角度稍偏就被判异常——"正常"的类内变化根本没被覆盖；
学松了：泛化过头，连异常也重建得很好——这正是你笔记里 Constricting 那篇论文要治的病。
两头都是死，根源一句话："学习"的前提是数据覆盖，4 个样本连"正常长什么样"都覆盖不全。

可行路线正是你写的那条：不做"学习"，做"比对"。记忆 最近邻不需要梯度、不需要训练集够大——4 个原型的特征原样存起来就是全部知识，测试点问一句"我见过你吗"即可。知识没有被压缩进模型权重，而是原封不动摆在仓库里，不存在"4 个样本学不透"的问题——它压根不学。

这也解释了整个 benchmark 的表格为什么长那样：BTF、PatchCore 系、Reg3D-AD 全是"比对"路线——在小样本真的考场上，这不是巧合，是唯一活路。
## 论文二：3D-CSAD —— 免训练、单样本的复杂曲面异常检测

> 一句话：不给训练数据、只要一个样本，利用"回转体零件的剖面彼此相似 → 剖面矩阵低秩"这一设计域知识，用 RPCA 把缺陷当稀疏异常项从低秩背景里抠出来。

### 2.1 定位：它和论文一是什么关系

| | Real3D-AD（Reg3D-AD） | 3D-CSAD |
|---|---|---|
| "正常"的定义 | 训练原型的记忆库 | 样本自身的低秩结构 |
| 需要训练数据 | 要（每类 4 个） | **完全不要** |
| 核心假设 | 缺陷点离记忆库远 | 缺陷破坏低秩结构 |
| 对零件形状的假设 | 无 | **轴对称回转体**（关键限制） |

读这篇的价值：它是"结构假设范式"的完整案例，也是你 Day 3"高度图+阈值"思想的矩阵版升级。同时注意它的实验是**自采合成数据**（不是 MVTec/Real3D）——评价它的适用范围时要带上这个心眼。

### 2.2 概念预习（本论文专有名词，逐个过）

**① 参考曲面（reference surface）**：零件的"名义表面"，即设计应该长成的样子。异常 = 实测表面与参考曲面的偏差。全文都在回答一个问题：**没有 CAD 模型、没有训练数据时，参考曲面从哪来？** 3D-CSAD 的答案：从样本自己的低秩结构里"长"出来。

**② 剖面（profile）与回转体**：车床/铣床加工的轴对称零件，可以看成一条 2D 轮廓线绕轴旋转扫出来的。这条 2D 轮廓线就是剖面。设计域知识：**同一零件的所有剖面形状相似**（图 1b）。

**③ 低秩矩阵（low-rank matrix）**：一个矩阵若各行（各剖面）都由少数几种"基形状"的线性组合构成，它的有效维度就低（矩阵的秩小）。把 n 条相似剖面叠成 n×p 的矩阵 M，**理论上 M 应该是低秩的**。

**④ RPCA（稳健主成分分析，Candès 2011）**：解这个问题——

$$\min_{L,S}\ \|L\|_* + \lambda\|S\|_1 \quad \text{s.t.}\quad M = L + S$$

- ‖L‖*：核范数 = 矩阵奇异值之和，是"矩阵秩"的最优凸松弛（让 L 低秩）
- ‖S‖₁：L1 范数 = 所有元素绝对值之和（让 S 稀疏）
- 翻译：**把观测矩阵拆成"平滑的背景 L" + "稀疏的异常 S"**。正常表面的变化都被 L 吸收，孤零零冒出来的缺陷留在 S 里
- 直觉类比：一张白墙上的照片。墙 = 低秩（甚至秩 1），照片 = 稀疏异常项。RPCA 就是把两者分开
- 为什么"稳健"：传统 PCA 会被离群点带偏，RPCA 显式建模了异常项所以不怕

**⑤ 模糊 c 均值（FCM）**：聚类算法，每个样本以"隶属度"软分配到 c 个类（式 1：最小化隶属度加权的到类中心距离，隶属度和为 1）。与普通 k-means 的差别：输出是概率而非硬标签，对边界模糊的数据稳。

**⑥ 函数方向离群度（FDO, Dai & Genton 2019）**：度量"一条曲线离一组曲线的中心有多远"，同时考虑偏差方向和幅值。用来揪出"离群剖面"。

### 2.3 方法三步流水线（第 III 节，逐段精讲）

**第 1 步：剖面生成（Profile Generation，III-B，图 4-5）**

输入点云 X ∈ R^{m×3}，输出剖面矩阵 M ∈ R^{n×p}。三个子步：

1. **切片**：取 m′=100 个平行于 xz 平面的等距切片平面，切出 3D 剖面并投影到各自平面；**长度 < l_norm=0.8 的短剖面直接丢掉**（归一化后包围盒最长边=1，太短的剖面没信息量）
2. **B 样条曲线拟合**：原始点云无结构——剖面点无序、长度不等。用三次 B 样条把每条剖面拟合成连续曲线（函数型数据分析 FDA 的做法，实现用 scikit-fda），得到函数曲线集 F
3. **定义域对齐**：各曲线长度不等怎么办？**外推不可靠，直接截断到公共定义域** [d₀, d₁] = [max d₀ᵢ, min d₁ᵢ]——取所有曲线定义域的交集，然后在公共域上等距重采样成 p 维向量（p = 长宽比 × 50）。n 条等长向量叠起来 = 剖面矩阵 M

**第 2 步：CSC 模块（III-C）——本论文的工程核心**

直接对 M 做 RPCA 会失败，两个原因（图 2 讲得很清楚）：
- **误差点**：点云在零件边缘处点分布散乱，切出来的剖面在边缘附近会"跑偏"（黄色 vs 黑色剖面）。这些误差点在矩阵里表现为稀疏大偏差——**比真缺陷还像缺陷**，RPCA 会优先把它们抓出来
- **低秩假设对整个表面不成立**：复杂零件（如螺栓：头部+杆部+螺纹）不同区域形状完全不同，一个矩阵装不下"低秩"

CSC 的两个子步各治一病：

1. **剖面聚类（CS, Component Segmentation）**：M 的**列** m′ⱼ 也是剖面（沿 y 轴切的"纵向剖面"）。同一基本组件内的列剖面形状相似 → 用 FCM 把 p 条列剖面聚成 c 组（Part1/2 取 c=2，螺栓 Part3 取 c=4）→ M 被列切成 c 个子矩阵 {M₁…M_c}。**整体不高秩、局部低秩**——分而治之
2. **离群剖面剔除（OPR, Outlier Profile Removal）**：每个子矩阵内用 FDO 找出离群列剖面并剔除。关键细节：**只剔除组件边界的离群，保留组件内部的离群**——因为缺陷可能就藏在组件内部，误杀就漏检了。剔除后得干净组件 M̄_k

**第 3 步：组件级 RPCA（III-D）**

对每个 M̄_k 独立做 RPCA（式 2-4）：

$$\bar M_k = L_k + S_k,\qquad \min_{S_k}\ \|\bar M_k - S_k\|_* + \lambda_k \|S_k\|_1,\qquad \lambda_k = \frac{n + \bar p_i}{6}$$

- λ 的取法值得记：**(行数+列数)/6**，不调参、按矩阵尺寸经验定——这是工程上"少一个超参少一分过拟合"的思路
- 各组件的 S_k 拼接回 S（式 5），再**把矩阵映射回原三维点云**：S 里每个元素对应剖面上一个采样点，找 X 中最近的实测点，把异常分数贴回去 → 异常分数图 A

### 2.4 实验与结果（第 IV 节，怎么读）

**数据**：自采合成——3 种零件（Part1/2 + 标准螺栓），在 CAD 模型上挖孔（圆锥形）和划痕（平面），从网格采样 10 万点/样本，加 σ=0.001 高斯噪声；共 60 个测试样本（2 类异常 × 30）。
**读法提醒**：这里要和论文一的 MVTec/Real3D 区分开——**没有公开基准对比、没有别的方法在同样数据上测过**，所以"大幅领先"的结论适用范围有限。它的价值在方法学，不在刷榜。

**指标**：Acc、BA、Precision、Recall、DICE（式 6，Dice = 2PR/(P+R)，综合查准查全）。

**对比方法与结果（表 II，本论文最震撼的一张表）**：

| 方法 | 本质 | 为什么崩 |
|---|---|---|
| FPFH-density | FPFH 特征 + 核密度估计 | 锐边/螺纹区的 FPFH 天然"离群"，**边缘误检泛滥**：Precision 低到 0.005–0.066 |
| PointSGRADE | 图表示 + 稀疏学习，自由曲面 | 假设参考面是局部平面 → 平划痕检出还行，但同样被边缘/螺纹打崩，Precision 0.005–0.063 |
| **Ours** | 低秩 + RPCA | DICE 0.86–0.96 |

三个方法 Recall 都不低（0.4–0.96），**差距全在 Precision**——大家都在"乱报"，3D-CSAD 靠低秩建模把误报压下去了。这个模式你在 Day 4 练习 4 见过：检出率 47% 但精确率 100% 的"宁缺毋滥"型。

**消融（表 III，一句话总结）**：

| 配置 | DICE |
|---|---|
| 去掉 CS + OPR | 0.1614 |
| 只去 CS（保留 OPR） | 0.2034 |
| 只去 OPR（保留 CS） | 0.6740 |
| 完整 CSC | **0.9621** |

读法：**CS（分割）比 OPR（清洗）更致命**——没有分割，低秩假设崩，RPCA 直接失灵；没有清洗，误差点抢戏但低秩骨架还在。两个子步各司其职，验证了 2.3 节的两个病因诊断。

### 2.5 局限与讨论（论文没明说、你要自己看出来的）

1. **轴对称假设是硬约束**：非回转体（铣出来的方腔、异形件）剖面不相似，低秩前提消失。它自己也写在开头："assumes that the focused manufacturing part is an axis-symmetric object"
2. **缺陷稀疏假设**：大面积缺陷（整圈崩边）会变成"低秩的一部分"被 L 吸收——RPCA 范式对"大面稀疏破坏"天然不敏感
3. **单样本无训练 = 也无法学"什么是正常变化"**：同一零件的加工纹理、刀痕若超出低秩模型表达力，会进 S 成为误报
4. 切片方向沿 xz——零件摆放姿态影响剖面质量（工程细节）

## 论文三：Constricting Normal Latent Space —— 用收缩损失限制 AE 的重建能力

> 一句话：重建式异常检测的老大难是"AE 连异常也重建得很好"；别人靠记忆库堵，它靠损失函数把潜空间压进范数球，测试时零额外开销。

### 3.1 定位：它在三篇中的位置

这篇是 **2D 视频异常检测**，技术上属你索引里 **1.3 重建系**（R3D-AD 一脉）的 2D 前辈。放在今天三篇里读的理由：Real3D-AD/3D-CSAD 解决了"用什么参考系比对"，这篇解决"**重建系方法的内部矛盾**"——三条路线拼起来才是完整的异常检测知识网。

### 3.2 核心矛盾（第 1 节，重建系的总病根）

重建式方法的标准剧本：AE 只用正常样本训练 → 期望"测试时异常重建不好 → 重建误差大 → 判异常"。

现实：**AE 泛化得太好，连异常也重建得有模有样**（图 3 的基线行：异常区域重建误差和正常区域差不多）。病根一句话：**潜空间没有任何约束，无限膨胀**，训练后期 AE 学会从巨大的潜空间里重建任何东西——正常或异常。

已有的两条对策及其代价：
| 对策 | 代表 | 代价 |
|---|---|---|
| 记忆机制 | MemAE、MNAD | 测试时要查记忆库，**推理有额外开销** |
| 伪异常注入 | STEAL、LNTRA | 需要"异常长什么样"的先验知识去造伪异常 |

本文第三策：**加一项损失直接压缩潜空间**，结构零改动、推理零开销。

### 3.3 方法（第 3 节，公式逐个拆）

**重建损失（式 1）**：L_R = (1/TCHW)‖X̂ − X‖²_F —— 普通的"重建得越像越好"。TCHW = 帧数×通道×高×宽，即对全部元素取均方误差。

**总损失（式 2）**：L = L_R + λL_C。λ 是收缩项的权重。

**关键操作**：把编码器输出的潜特征 F（尺寸 T′×C′×H′×W′）在通道维与时间维上展平成 F_{j,i} ∈ R^{T′×C′}，对**每个空间位置**的潜向量施加约束。即：同时约束外观信息（通道）和时间信息（帧）。

**收缩损失 A：压到球内（式 3）**：

$$L_C = \frac{1}{H'W'} \sum_{j,i} \max(0,\ \|F_{j,i}\|_2 - \alpha)$$

- ‖·‖₂ 是 L2 范数，α 是球的半径
- 范数 ≤ α（球内）→ 损失 0；超出 → 罚
- 效果：正常数据的潜特征被约束在半径 α 的球内，潜空间"边界"明确（图 2a）

**收缩损失 B：压到球面（式 4）**：

$$L_C = \frac{1}{H'W'} \sum_{j,i} \big|\ \|F_{j,i}\|_2 - \alpha\ \big|$$

- 范数恰好 = α 才零损失；**无论偏大偏小都罚**（绝对值）
- 比球内版更强：不仅限界，还把正常特征"贴"到球面上（图 2b）

**直觉对比**：球内版是"给潜空间修围墙"，球面版是"把正常特征钉在球壳上"。球面版约束更强，作者自己的超参实验（图 4）显示：α 太小时球面版容易翻车——过度收缩连正常数据都重建不了，AE 彻底摆烂。

**推理（式 5）**：对第 t 帧，用 PSNR（峰值信噪比，重建质量的度量）做正常性度量 → 视频内 min-max 归一化得 N_t → **A_t = 1 − N_t** 即异常分数。分数量化细节：用第 9 帧的重建结果算分数。

**实现细节（复现相关）**：
- 输入输出尺寸 16×1×256×256（16 帧灰度clip）
- **移除编码器最后一个 LeakyReLU**——让潜变量能同等覆盖正负区，收缩损失才能对称地施加。这是"损失与网络结构要配套设计"的典型案例
- 默认 λ=0.0001；α 按数据集调（Ped2 用 0.1 / 球面用 10，其余 1 / 100）
- 5 次重复取最好

### 3.4 结果怎么读（表 1 + 图 4）

**三个台阶**：
1. 基线 AE（只 L_R）：Ped2 92.49 / Ave 81.47 / Sh 71.28
2. 加收缩后：94.66/82.93/71.35（球内）、94.05/82.14/71.39（球面）——**两种收缩都稳定超过基线**，方法成立
3. 和记忆网络（MemAE 94.1/83.3/71.2）比：**性能相当，但测试无额外开销**——这就是论文的核心卖点："用损失约束潜空间 ≈ 用记忆约束潜空间"
4. 和伪异常法（STEAL 98.4/87.1/73.7）比：仍有差距。作者归因：伪异常法有"异常是什么"的先验。诚实定位：**无先验方法中的最优一档**

**图 4 超参分析**：横轴 λ / α，纵轴 AUC。红线（本文）大面积高于绿虚线（基线）= 对超参稳健；例外是球面版 + 小 α → 过度收缩翻车。这个"稳健区间"图是调参时的地图。

### 3.5 局限（自己补的，论文只一句话带过）

1. 提升幅度有限（+1~2 个点）——潜空间约束是"缓解"不是"根治" AE 泛化
2. 压缩潜空间 ⟹ 重建容量下降，正常数据中复杂模式的重建质量会受损（球面版 α 过小时的表现就是极端化）
3. 视频领域（Ped2 等老数据集）的工业价值弱于 3D 质检——它的意义在方法论：你库里 1.3 重建系的 R3D-AD 等 3D 重建方法，面对"3D 版 AE 泛化"问题时，这篇的损失约束思路可以直接搬

### 3.6 📝 自检三问（论文三）

**Q1**：AE"连异常也重建"的根子是什么？记忆机制和收缩损失分别怎么治？
<details><summary>答题支架</summary>

- 根子：潜空间无约束、可无限膨胀，AE 学会从巨大潜空间重建任意输入
- 记忆机制：限"能用什么"（潜变量必须落在记忆向量张成的子空间里）——结构改动、推理要查库
- 收缩损失：限"能有多大"（潜向量范数 ≤ α）——只改损失、推理零开销
- 检验：能否画出"潜空间膨胀"这个因果链
</details>

**Q2**：球内版（式 3）和球面版（式 4）差在哪？为什么 α 过小时球面版更危险？
<details><summary>答题支架</summary>

- 球内：只罚"太大"（max(0, ‖F‖−α)）；球面：大小都罚（|‖F‖−α|），把正常特征钉到球壳上，约束更强
- α 过小 + 球面：正常特征被强拉到极小半径，AE 容量被掐死，正常也重建不动 → 误差信号失去区分度（图 4d 左段翻车区）
- 加分项：球面版 α 反而取得大（Ped2 取 10），说明强约束需要大空间补偿
</details>

**Q3**：为什么推理用 PSNR，最后还要 A_t = 1 − N_t 归一化？
<details><summary>答题支架</summary>

- PSNR 是"重建质量"：正常帧重建好 → PSNR 高 → 正常性高；异常帧相反
- 不同视频亮度/对比度不同，PSNR 绝对值不可跨视频比较 → 视频内 min-max 归一化成 N_t ∈ [0,1]
- A_t = 1 − N_t 把"正常性"翻成"异常分"，方向统一为越大越异常（和 Real3D-AD 的距离分同方向）
- 加分项：指出"视频内归一化"意味着分数是相对的，不能跨视频比绝对值
</details>

## 术语速查

| 术语 | 一句话 |
|---|---|
| OCC / 无监督 AD | 只给正常样本训练，没见过即异常 |
| AUROC / AUPR | 排序能力 / 不平衡下的严格排序能力；0.5=瞎猜 |
| 原型 prototype | 无缺陷完整工件，Real3D-AD 每类仅 4 个 |
| 记忆库 memory bank | 正常特征库，测试样本离它越远越异常（PatchCore 机制） |
| Coreset 采样 | 从大数据集贪心选代表子集 |
| FPFH | 点云局部几何特征 33 维（法线+曲率邻域统计） |
| RANSAC 配准 | 随机抽样一致性，把两个点云对齐到同一坐标系 |
| 低秩 / 核范数 | 矩阵有效维度少 / 秩的凸松弛 |
| RPCA | M = 低秩 L + 稀疏 S，缺陷留在 S |
| FCM / FDO | 模糊聚类 / 函数型数据的离群度 |
| PSNR | 重建质量分，正常帧高、异常帧低 |
